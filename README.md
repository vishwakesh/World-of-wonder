# World-of-wonder

WONDER OF WORLD — One World. Countless Wonders.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:3000`.

## Demo account

- Username: `wonder_admin`
- Password: `demo1234`

## Notes

- Uses SQLite for persistent metadata and local `uploads/` file storage for images.
- Uploads are moderated (`pending` until approved by admin endpoint).
- External dependency for map tiles: OpenStreetMap + Leaflet CDN.
